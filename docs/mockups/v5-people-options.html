Data changes behind these

  1. Closeness tier per household (Inner · Close · Extended · Wider), derived from the closest relation, editable. Drives order, bulk decisions and the room line.
  2. Friendly branch names ("Mark's dad's side") instead of workbook titles; branches become a small list you can rename.
  3. Friend fields: circle, who knows them (Mark · Angela · both), tier, "we went to theirs", plus-one as a named partner or an unnamed +1.
  4. Unnamed kids as a count on the household (no more "Child 1/2/3" people).
  5. Generation from links where possible (fixes great-aunts shown as grandparents); "Not placed yet" tray for the rest.
  6. One decision display: dot + 3-way control; undecided gets its own "?" mark.

Recommended combination

  1. D room check on top, always.
  2. A1 rings as the default view (A3's density on wide screens via a compact toggle).
  3. B1 outline tree as the "Family" view, with the "Not placed yet" tray.
  4. C1 friend shortlist by tier, also shown as the Friends ring in A1.

Views shrink from four (Decide · Garden · Friends · Envelopes) to three: Decide (rings) · Family (tree) · Friends (shortlist); envelopes move to an Export button.
